# 情话中转站 · DSH 插件

> 在 DSH 里注册情话中转站账号，自动创建各分组 API Key，模型开箱即用。

**站点**：https://qinghuaend.cn
**适用**：DeepSeek Harness（DSH）网页端 / 桌面端

装好插件后，你不用再打开浏览器建 Key、抄 Base URL、手写模型列表——在 DSH 的「设置 → 中转站账户」里注册一次，点一下同步，模型就直接出现在模型选择器里。

---

## 三步接入

1. **安装插件**（见下方安装）
2. **注册 / 登录**：设置 → 中转站账户 → 输入邮箱获取验证码 → 注册
3. **同步模型**：点「同步分组与模型」，然后去「设置 → 模型」选模型开聊

---

## 这个插件做了什么

| 步骤 | 以前 | 现在 |
|---|---|---|
| 注册 | 打开网站、收验证码、记密码 | DSH 设置页内完成 |
| 建 Key | 每个分组手动建一次，复制保存 | 自动按分组创建，写入 DSH 凭据库 |
| 配置模型 | 找 Base URL、抄模型 ID、拼配置 | 自动生成模型路由 |
| 充值 | 回网站充值再回来 | 设置页内下单、扫码、查单 |

分组上下线时也只需再点一次「同步分组与模型」：新增分组自动出现，下线分组连同 Key 一起清理。

## 支持的分组

| 分组 | 协议 | 说明 |
|---|---|---|
| GPT_官key组 | OpenAI 兼容 | gpt-6.1-sol / gpt-6-astra / gpt-6-sol / gpt-6-luna / gpt-5.6-sol |
| ccpro组 | Anthropic（经兼容层） | claude-fable-5 / claude-opus-5-5 / claude-sonnet-5-5 |
| ccmax组 | Anthropic（经兼容层） | 同上，独立渠道 |
| DeepSeek | OpenAI 兼容 | deepseek-v4.1-flash-1017 |

- 模型清单一律以站点「模型广场」为准，不会导入你用不了的模型；
- 导入时已声明图片输入、100 万上下文、全档位推理强度，选模型即可用；
- 视频类分组（如 seedance）不会进入对话模型列表。

## 安装

### 方式一：Agent 安装（推荐）

把仓库下载到本地后，在 DSH 里新建一个会话，把仓库路径发给 Agent 并说：

```
帮我安装这个 DSH 插件：<仓库绝对路径>
```

Agent 会调用插件管理器完成安装。

### 方式二：手动安装

1. 下载本仓库到本地目录；
2. 在 DSH 中让 Agent 执行：`plugin_manager install_bundle <仓库绝对路径>`；
3. 刷新 DSH 页面。

安装完成后，左侧「设置」里会多出一项 **中转站账户**（在「账号」下面）。

---

## 首次使用

1. 打开 设置 → 中转站账户；
2. 选「注册」，填邮箱 → 点「发送验证码」→ 填昵称和密码（至少 12 位）和验证码 → 注册；
3. 回到卡片点 **「同步分组与模型」**；
4. 打开 设置 → 模型，能看到「情话中转站 · GPT_官key组」等分组，选模型开始对话。

已经有钱包余额的，直接在「充值」区输入金额、选择渠道（微信扫码）、生成订单支付即可。

## 关于思维链

- **Claude 组**：可以看到完整思考过程。
- **GPT 组**：复杂问题会显示思考；简单问题（如"你是什么模型"）上游不会产生思考内容，属正常现象。
- **DeepSeek 组**：思考过程会显示，但这个模型习惯把草稿和工具调用计划写进思考里，看起来会比较碎——这是模型自身行为。若不想看，可在配置里加：

```yaml
config:
  hideReasoning: ['qinghua-deepseek']
```

## 常见问题

**Q：插件收费吗？**
插件免费。费用只来自你在情话中转站的实际用量与充值。

**Q：Key 安全吗？**
插件运行在你自己的 DSH 里，API Key 写入本机 DSH 凭据库，不写配置文件、不上传；所有请求由本机 Host 代理，浏览器侧拿不到密钥。

**Q：换了电脑还能用吗？**
重新安装插件并登录同一账号即可，Key 会从你的账号重新拉取。

**Q：提示「同步失败 / 分组为空」？**
先确认账号已通过邮箱验证；若是新注册，稍等片刻再点一次同步。仍有问题把报错截图发到站点工单。

**Q：充值没到账？**
订单走站点自身支付渠道与回调；超过订单有效期未到账，请在站点后台提交订单号，由管理员核对。
